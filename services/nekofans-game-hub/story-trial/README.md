# Nekofans 剧情棋局 · 开源与抹除

在 Nekofans 的「分享游戏 → 高级设置」打开白方、黑方和女神。三个入口打开同一局的独立本机视角。双方先各自提交一条规则，经女神批准后开局。

- **开源（白方）**。退场棋子把自己的走法加入共享池。双方都能让自己的棋子借用池里的走法，借用会用掉本回合的走子机会，仍须保证本方国王安全。
- **抹除笔记（黑方）**。每个黑方回合可以额外尝试一次，只有提交的名字与目标棋子的真名一致才成功。失败也消耗本回合的尝试，黑方仍可以正常走子。白王预设真名「梁文峰」，误称「梁武帝」不能命中。棋子真名仅女神可查和调整。抹除国王会结束对局。
- **猜中规则获胜**。任一方可提交猜测。女神确认猜中后立刻判胜，双方规则随终局揭晓。猜测原文和未公开规则只对提交方及女神可见。

女神默认审批走子，也可以切换为即时走子。棋盘、公开行动和结果实时同步。每个视角的本机地址带独立席位凭证，请将其只交给该角色的操作者。

启动后可以人工对局和裁定。工作台账号已登录并成功绑定本局时，白方可以请求大肥鱼决策。服务端只把本方规则、公开棋局和合法动作传给队友。模型调用需要在白方页面主动触发，失败时不会自动走子。

## 开发与验证

在仓库根目录运行：

```sh
node --test services/nekofans-game-hub/story-trial/tests/*.test.*
node --test tests/neko-workbench/story-prototype-launcher.test.cjs
```

如需单独启动，在本目录运行 `npm start`，打开 `http://127.0.0.1:8787` 并创建剧情房间。演示脚本 `npm run demo` 使用本机服务。独立运行读取本目录 `data/`，工作台使用个人数据目录下的 `story-chess/`。工作台模式的三视角共用当前房间，停止适配器后再打开会创建新局。测试使用临时房间及合成模型响应。

本入口仅监听本机回环地址。工作台的聊天室联机邀请仍使用 [私密规则棋局服务](../README.md)。API 见 [接口说明](docs/API.md)。
