# 工作台模型桥

Nekofans 主进程启动随工作台分发的剧情服务并绑定本机模型桥。剧情服务使用系统分配的回环端口。三个席位的访问凭证仅由主进程打开到对应的本机页面，工作台界面接收房间号与连接状态。

账号未登录时可以人工对局。绑定成功后，白方可以请求大肥鱼做决策。剧情服务从白方投影构造 `nekofans.game-player.v1`，使用工作台模型桥的 `/v1/decision`。模型桥再按允许字段重建上下文。房间服务检验返回的动作、房间版本和回合。女神独立审核双方的规则和猜测，真名抹除按服务端场景确定性比对。

开发时也可显式将 `NEKO_STORY_PROJECT_DIR` 指向可信的兼容剧情服务。
