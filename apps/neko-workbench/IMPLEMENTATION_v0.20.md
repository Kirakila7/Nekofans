# v0.20 · 在工作台内开始养鱼

日期：2026-10-27（Asia/Shanghai）。范围：可选 N.E.K.O. 工作台；兼容 v0.19 像素形象。

主角色右键提供“开始养鱼 / 暂停养鱼”，没有首次引导。具体设置位于现有工作台的右侧面板，可从左下角“养鱼”或工作台选项打开；打开设置会收起社区原生视图，返回按钮或 Escape 关闭面板。角色名、人设、喜好、作息、B站登录、日记、推送和互动开关共用一份配置。

启动先查询 DeepSeek 账号的安全状态投影，再检查 B站登录；未登录时打开工作台中的对应入口，成功登录后继续先前启动请求。等待登录时也可暂停；取消二维码、暂停或关闭工作台会使旧启动请求失效。养鱼使用工作台已有模型路由，主角色独立 Chat API 仍保持原配置，不复制或向渲染进程发送模型凭据。

默认暂停。默认每天至多一次唤醒、初筛三个视频，只阅读与写本地日记。工作台设置中的 B站写操作总开关和相应互动功能均需用户启用；网络工具在调用平台写接口前读取当前开关，配置缺失或已暂停则拒绝。扫码生成与账号验证只查询登录接口。入口不收费，用户自行向模型服务商付费。

固定内置 Alterssss/dsh-bili-whale 0.4.6，源提交 `8b0009f8ce2ebdc421afcb2e727b19ac18912ec6`。保留 MIT、原 README/NOTICE、原文件 SHA256，并另列本地适配说明及适配后 SHA256。QR 依赖使用 qrcode 1.5.4 离线 bundle，保留 qrcode/pngjs/dijkstrajs 各自许可；运行时无需下载 npm 包。未打包 ffmpeg，缺失时可使用字幕/文本能力。

养鱼数据根是当前工作区的 `fish-care/`，包含独立配置、日记和 B站凭据；使用专用 `BILI_WHALE_HOME` / `BILI_WHALE_DSH_HOME`，不改变 HOME/USERPROFILE。DSH 本身仍使用当前工作台的独立 DSH_HOME 与 workspace-write。用户配置和人设不覆盖；应用拥有的 CLI 启动器随安装路径刷新。文件菜单隐藏内部配置和凭据，只额外列出两本日记。

暂停清除作息/监听定时器、取消在途投递、关闭直播监听子进程，并请求取消确切养鱼会话及它自己拥有的 jobs，不触碰其他会话或公共 jobs。拒绝取消的结果显示错误。匹配养鱼会话的原生 agent/error 会暂停养鱼；其他会话出错不会误停。账号退出也暂停运行中的养鱼。暂停表示已发出取消请求，正在执行的平台请求可能已经完成，不能撤回已发生的操作。
