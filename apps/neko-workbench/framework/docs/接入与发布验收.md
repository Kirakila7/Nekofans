# 接入与发布验收

## 当前交付

本包新增双记忆合同、右键菜单定义、首启流程、安装分发规格，以及一个可执行的同步参考内核。参考内核使用适配器模拟测试；未连接本机真实 N.E.K.O.、未改写现有日记、未完成聊天 API 连接，也没有产出已签名安装器。

## 原生接入顺序

1. 在当前轻量版主 Agent 右键添加唯一“养鱼”入口，所有相关设置挂在此集合内。不要恢复被用户取消的常驻名称标签或工作台面板。
2. 实现本地角色存储、日记适配器和可靠同步事件库；保持默认日记模式可单独工作。
3. 将第一版聊天 API 的上下文构建接到 MemoryRouter，保持主角色与 DSH 执行层分离。
4. dsh-bili-whale 接入专用生活会话，将真实经历送入同一角色的日记适配器；其会话不等于现有子代理目录中的天然子项，需要明确绑定。
5. 为目标 N.E.K.O. 版本补齐兼容网关，验证读取、写入、去重、来源、确认状态、私有内容和删除操作。必要能力全部可用后才允许切换模式。
6. 在真实双方连接上验证协议，再接入一键安装、更新和首启向导。

## 关键验收

| 场景 | 应有结果 |
|---|---|
| 同一段日记重复同步 10 次 | 不重复增加记忆 |
| N.E.K.O. → 日记 → N.E.K.O. | 保留原事件 ID，不无限循环或重复提炼 |
| 两边同时编辑同一条偏好 | 保留两版，提示一次冲突，不能静默覆盖 |
| 一边删除，另一边恢复旧备份 | 删除不会被旧记录自动复活 |
| 私人日记同步 | 只进入同角色私有存储，不出现在公开日记与通知 |
| 另一角色的资料出现在输入批次 | 拒绝写入大肥鱼空间 |
| N.E.K.O. 离线 | 日记与聊天继续保存，显示待同步，切换保留原模式 |
| 写入失败、进程中断、重启 | 不提前推进游标；可从检查点重试 |
| 切换记忆方式或皮肤 | 同一角色、人设与原始聊天保持不变 |
| 子代理在工作时开始同步或暂停养鱼 | 主角色不跟随工作；用户任务不被停止 |
| 没有配置聊天 API 的新安装 | 进入单个配置向导，不伪装已可产生模型回复 |

## “下载即可养鱼”的发布门槛

Windows 安装器与 Apple Silicon macOS 安装包分别构建。安装包应包含合法分发的桌面运行时、必要 DSH 运行时、默认素材、日记适配器与向导；依赖不可只引用开发者电脑里的绝对路径。

首次运行自动检查端口、版本与账号配置；无需用户运行终端命令。选择进阶记忆时检测或安装兼容组件。升级只替换程序，保留角色存档、日记、事件库和恢复点。API 密钥和 B站凭据不随源码包或用户导出默认携带。

发布前须在没有本机开发依赖的干净机器上，完成安装、首次配置、两种模式切换、离线重启和恢复测试，并核对运行时/素材许可及平台签名。当前源码框架 ZIP 不满足这一安装包定义。
