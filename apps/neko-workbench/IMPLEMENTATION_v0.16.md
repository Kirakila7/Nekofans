# 工作台 0.16.0：可选 N.E.K.O. 跑动小猫

中号真实工作会话（本轮用户所说的 subsection）与小号原生 subagent 都能选择 N.E.K.O. 白色小猫形象。使用原生蓝蝴蝶结白猫 GIF，保留三档尺寸、真实任务来源、停止、导航、自动退场与常驻规则。

主角色右键 → 设置 → 任务默认形象 / 子代理默认形象，分别设置两类默认值。每只任务或帮手右键 → 形象，选择“跟随默认 / 原有角色 / N.E.K.O. 跑动小猫”。默认值和单独选择均保存至当前工作台存档；原生元数据刷新、重启和迟到身份修正不清除单独选择。初始默认仍是原有角色，主角色不使用这个替换器。

## 素材与显示

- 原始来源固定为 Project-N-E-K-O/N.E.K.O 的 `a3c82b5a8eeb63afcc0a344fa1113a176b8defd2`；四份 GIF 与该版本 git blob 一致，未重绘。文件来源、SHA-256 与 Git blob 记录在 `assets/neko-cat/SOURCE.json`，保留原仓库 Apache 2.0 许可全文。
- `cat-idle-cat4-1.gif` 用于运行中走动；`cat-idle-cat4-2.gif` 用于完成伸展；`cat-idle-cat4-3.gif` 用于空闲张望；`cat-idle-cat-move-3.gif` 用于拖拽悬空。
- 走动只发生在自身画面内，不改桌面窗口位置。输入框使用小猫专用头顶留白，避免覆盖耳朵。
- 减少动态效果和素材加载失败使用从原生空闲 GIF 第 0 帧导出的静态 PNG。选择、状态和资源路径都来自本地白名单。
- 切为小猫时暂停并释放原角色视频，使用 generation fence 阻止迟到的 loadeddata 回调恢复旧画面；切回时恢复原有工作动画与气泡，窗口和会话保持不变。
