# 工作台 0.15.0：三档真实角色

主角色继续负责独立陪伴聊天，DSH 工作会话与原生子代理分别显示为中号任务和小号帮手。默认画面宽度为 462 / 323 / 239，约为 100% / 70% / 52%；改变主角色尺寸时按比例调整。

## 行为与来源

- 只有本人真实输入或恢复出的本人会话历史能建立任务身份；空会话、自动续跑状态、委派提示不会凭空建立中号角色。普通 fork 不因存在父会话而成为 subagent。
- 小号身份继续取自原生 catalog / origin / descriptor。迟到的子代理身份替换中号角色，保留昵称、常驻和位置，避免同一会话重复出现。
- 任务与帮手共用名额，默认 5，主角色另计。常驻优先，其余按 15 秒轮换；默认位置按实际窗口宽高换行，窄工作区使用共同缩放。用户拖动的位置保留，并限制在工作区内。
- 结束反馈约 10 秒后退场；常驻不退场。后台 job 仍在运行时不会因主回合结束而退场。结算只接受原生事实，聚合 completed / killed / failed，未知结果不判成功。
- 停止只取消本会话的 Agent 与精确 owner 的真实 job；能力缺失、取消失败或 accepted:false 使用局部提示，不把整个工作台改成断线，也不提前清掉真实运行状态。
- 点击任务或“在工作台继续任务”打开固定的真实 session。外部任务导航先收起原生社区面板，再调用现有 uiWorkspace.openSession；保留原 coding DOM 与草稿。

恢复时按快照、事件游标后的实时事件、最终 job 注册表依次核对，旧批次的取消不污染新任务；同一批次的失败不会因最后一个 job 成功或恢复期间结束而丢失。纯历史结束记录不作为本次刚完成的反馈。
