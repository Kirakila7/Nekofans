# v0.17 · 三类角色的动态形象与尺寸

日期：2026-10-27（Asia/Shanghai）。范围仅为可选 N.E.K.O. 工作台及其测试。

## 使用方式

- 主角色、中号任务、小号 subagent 均可右键 → 形象，选择大肥鱼、N.E.K.O. 跑动小猫、Claude 娘或 Gemini 小猫。
- 主角色菜单 → 设置，可分别设置三类角色的默认形象。单只角色可以覆盖，或恢复“跟随默认”。
- 右键 → 形象 → 形象大小，支持默认值及 40%、55%、65%、80%、100%。N.E.K.O. 小猫默认缩到原先的 65%，仍保留三档角色的相对尺寸。
- “导入自定义动图…”接受本机多帧 GIF/WebP，最多 4 MB、长宽 2048 像素、2～10000 帧。静态图片会被拒绝。原始动画字节和本地首帧保存在当前工作台存档，不保存原文件路径，也不上传图片。

显示名、任务归属、会话、模型、聊天与记忆路由不随形象选择改变。输入框、气泡和点击区域随画面尺寸调整。

## 动画来源与状态

Claude 和 Gemini 来自 [fywdy/chatgpt-chibi-pets](https://github.com/fywdy/chatgpt-chibi-pets)，固定提交 `d5bbb27c79e5c08e8b8ab44d4023cd35a67418e2`，分别为 `claude-orange-scholar-chibi-v3` 和 `gemini-star-cat-chibi-v1`。每套保留九个原始 WebP；18 个文件均有 4～8 帧，并且各含多个不同画面，文件字节与来源哈希一致。尺寸为 192×208。

实际状态映射为：空闲 → idle，思考 → review，执行 → running，成功 → jumping，失败 → failed，等待/停止中 → waiting，拖拽 → waving。左右跑动文件也随来源包保留。正常状态直接播放原始多帧图片，状态广播不会重复重置相同动画。

N.E.K.O. 白猫沿用 v0.16 的原生 GIF。系统启用“减少动态效果”，或媒体加载失败时，使用对应的本地静帧。切换到图片形象时暂停、释放并隔离原视频的延迟加载回调，切回原有形象可继续原动作反馈。

Claude/Gemini 美术采用 **CC BY-NC 4.0，署名、非商业使用**，属于非官方同人素材。完整 LICENSE、NOTICE、固定来源、哈希、帧数和时长见 `assets/ai-girls/`。N.E.K.O. 白猫和代码继续遵循各自许可。

## 本地导入解码

主进程检查文件类型、字节上限和 GIF/WebP 的真实帧结构，再通过隐藏、隔离的 Chromium 窗口解码。该窗口关闭 Node 集成、启用 sandbox/contextIsolation，以 CSP 限制为本地 data 图片，拒绝导航和新窗口，解码结果限制尺寸并生成 PNG 首帧，完成或失败均销毁窗口。

使用 Chromium 是因为 Electron 的 nativeImage 无法解码部分动画 GIF。导入保留原动画，不将静态 PNG 包装成动图。未增加可供普通渲染页面调用的任意文件读取接口。
