# 简化账号界面与隐私设置

未登录时，侧栏显示 N.E.K.O. 图标，点击后继续使用 DSH 原生账号菜单。账号菜单的反馈入口、重复的账号/余额卡片和首次“开始使用”引导按现有简化设计处理；手动登录仍使用原生授权流程。

原生 Session Log 上传选项保留在设置页的 **隐私 / 高级设置** 分组中。分组默认收起，但入口始终显示实际开关状态：已开启、已关闭或状态待确认。展开后操作的是原来的 DSH 开关，保存、失败提示和持久化仍由 DSH 处理。展开、收起和读取状态都不改变上传偏好；退出插件也不会撤销用户作出的选择。

界面只添加自己的折叠入口、样式标记与状态文字，不移动、克隆或替换原生开关。关闭分组时，隐藏区域内的键盘焦点会回到入口。设置重开、语言切换和插件卸载会正确清理。账号卡片隐藏规则仅作用于适配器明确标记的节点，卸载时恢复。

验证：

```sh
npm test
npm run check:neko
# NEKO_DOM_DEPS 指向已安装 jsdom 的目录。
NEKO_DOM_DEPS=/absolute/path/to/dom-deps node apps/neko-workbench/embedded-dsh/check-privacy-settings-dom.cjs
```

DOM 验证不连接真实账号，不发送会话内容，也不修改实际上传设置。
