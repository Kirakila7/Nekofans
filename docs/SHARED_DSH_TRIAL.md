# N.E.K.O. 工作台试用版

本机试用入口使用现有 `~/.dsh` 和 `desktop` profile。账号、模型配置、已安装插件与会话直接共用原版 DSH，不再使用临时隔离 DSH 存档；工作台的头像、桌宠位置、私人聊天和 Electron 缓存保存在持久的工作台用户数据目录中。

界面保留当前工作区/休闲区、N.E.K.O. 社区、B站、养鱼与 QQ 连接设置，加入喷泉出场和 DBSCAN 邻近聚类与避让。子代理只来自真实任务。养鱼/QQ 的自动运行仍由用户在各自设置中开启。

双击试用应用打开工作台，或双击随附的启动命令。插件入口在大肥鱼旁的四宫格工具按钮中。账号、模型和插件设置与原版共用，修改会在原版生效。试用应用的启动覆盖层隐藏旧 dsh-pet，避免与 N.E.K.O. 主角色重复；不修改原版的宠物启用配置。

启动前需正常退出原版 DSH，避免两个执行进程同时使用同一 profile。退出试用版后可重新打开原版。原有会话和插件无需搬回。

开发参数：`NEKO_WORKBENCH_DSH_HOME` 指向已有 DSH 数据目录，`NEKO_WORKBENCH_DSH_PROFILE` 默认 `desktop`。未显式提供前者时仍支持隔离的离线验证；测试不会读取真实凭据。服务继续只监听 `127.0.0.1`，审批与工作区权限继续生效。
