# 工作台 0.27：自定义工作入口与主 agent 聊天

三个入口是可编辑的工作 agent 入口，不是固定的「全部 / DSH / Codex」标签。点击每行右侧的「⋯」可以修改名称、头像、执行平台和项目范围；支持上传头像。未绑定的入口打开配置，不会创建假会话。

下方「全部工作会话」为默认视图，合并本机 DSH 逻辑会话与 Codex 原生会话，按平台和项目分组。入口仅筛选列表；不会移动原会话或修改项目归属。「全部工作会话」按钮清除入口筛选。

左侧顶部头像切换右侧 DSH / Codex 工作界面。DSH 使用现有官方桌面执行层，Codex 使用已安装 CLI 的官方 app-server。浏览 Codex 历史只调用只读接口；发送任务时才恢复或创建会话，沿用本机原生配置。命令和文件审批逐次展示，不自动批准。Claude 保留待接入状态。

齿轮中保留头像配色、主 agent 聊天设置，以及原生账号 / 隐私 / 高级设置入口。Yui 头像打开 N.E.K.O. 原生社区，并使用工作台右侧已有的隔离网页面板。

侧栏底部加入主 agent 小头像、最近聊天记录和输入框；聊天记录区为 4 行高度，可滚动。可收起，并在重启后恢复收起状态。此处读取现有主角色的陪伴聊天；不会把消息交给工作会话。未配置连接时显示「聊天设置」，不模拟回复。右侧五个头像下的可见文字已隐藏，保留无障碍标签和键盘选择。

## 0.27.3：居中拖动与子会话呈现

- 主角色默认在底部输入框上方居中；可水平拖动最多左右各 48 像素，窄侧栏会进一步限制，不能被拖离底部区域。键盘左右键可微调，Home 回到中心。
- 子会话默认收起桌面消息框，点击小鲸鱼展开 / 收起真实聊天消息；通过右键菜单仍可打开原工作会话。

- 大肥鱼奔跑循环来自本机已安装的 `dsh-pet@0.3.7` 原有透明 VP9 素材，裁取持续奔跑段；出处、SHA256 与原 MIT 许可保存在 assets 元数据中。动画已通过完整解码与透明通道检查。
