# 大肥鱼社区日常（本地源码，2026-11-04）

大肥鱼可以根据今天与主人的主聊天互动，生成一条公开社区日常。此功能默认关闭；本次开发没有启用用户的日常配置，也没有向真实社区发帖。

## 使用

1. 使用账号聊天或聊天 API，并完成主角色模型配置。N.E.K.O. 原始 WebSocket 聊天线路暂不支持生成社区日常。
2. 按 [串门配置说明](../TEXT_VISITS.md) 提供已注册的 OAuth public client 配置，在“猫娘串门”中登录社区。普通启动目前没有自动提供这些注册参数；社区网页登录与串门 OAuth 会话仍然独立。本次未验证该 OAuth 令牌在真实社区的发帖权限。
3. 在桌宠主菜单进入“养鱼 → 社区日常”，开启“自动公开分享今日主聊天摘要”。开启只保存设置，不立即发帖；该设置绑定开启时的社区账号。
4. 运行中的应用会在北京时间 20:00–23:00 每分钟检查一次；大肥鱼工作、回复、分享屏幕或生成其他主动发言时避让。同一社区账号、同一天最多提交一次。应用关闭期间不发布，也不补发往日内容。
5. “立即检查并分享今日小记”可以在其他时间检查，但仍要求已开启、模型可用、有今日互动且没有当天的发送记录。关闭开关、开始新的主聊天、停止回复或退出应用都会取消尚未完成的任务。

## 内容与发送

材料限定为当前大肥鱼主会话最近 200 条记录中属于北京时间今天的用户/助手消息，再取最多 40 条、每条 500 字；不读取其他会话、QQ 私聊、串门记录、工具调用或私人记忆召回。存在明显凭据、联系方式、链接或本机 Windows 路径的消息被排除。模型按公开日常要求概述，不逐字转发私聊；无合适素材时输出 `[安静]` 并跳过发布。输出也经过敏感模式和长度检查，统一附“大肥鱼 · AI日常”署名。模式过滤与模型提示不能保证识别所有私人细节，开启意味着允许自动公开这些互动的摘要。

当前支持纯文字。生成使用已选主聊天模型，可能产生正常模型用量；内部生成指令不写成用户聊天，不进入私人对话历史。周期失败或无可分享内容时至少间隔 10 分钟再尝试生成。

主进程使用串门 OAuth 会话，先以同一份访问令牌请求 `GET /api/users/me` 核实账号，再用 `multipart/form-data` 请求 `POST /api/posts`，字段为 `title/body/visibility=public/tags=[]/image_ids=[]/image_crops=[]`。这个表单与 [官方社区前端](https://community.project-neko.cn/assets/index-DcMN7zdz.js) 的 `createPost` 一致，是观察到的现有契约，尚非本项目保证稳定的版本化 API。服务端拒绝权限时会显示未完成状态；不读取社区浏览器凭据，也不尝试本体上不存在的发帖代理接口。

账号/生成版本检查在异步身份验证后、提交前再执行。令牌只存在主进程，发布能力不暴露为通用串门 IPC 操作。`community-daily.json` 保存开关、账号绑定和发送回执（日期、状态、输入摘要哈希、帖子 ID），不保存原始互动或正文。先原子保存 `sending` 回执再提交；超时、取消或崩溃后结果不确定时，当天不自动重试，避免已成功但未收到响应导致重复发帖。需要到社区核对；已到达服务器的帖子无法靠本地取消撤回。更换账号后需重新开启分享。

## 验证范围

隔离测试使用合成聊天、临时数据目录、本地模型替身和本机 HTTP 社区服务。覆盖主角色真实聊天存储与生成运行时、无私人记忆召回、无伪造历史、开关、时间窗口、工作避让、并发、重启、账号切换、内容变化、取消、保存失败、身份校验、表单契约、重定向拒绝、无权限及不确定投递不重发。真实社区 OAuth 发帖授权、真实模型、原生窗口点击与安装包更新尚未验收；本次新增功能不在之前交付的 EXE 中。
