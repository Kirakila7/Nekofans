## 只读预检

在 `neko-fish` 根目录执行：

```powershell
node scripts/check-distribution.mjs
node scripts/check-distribution.mjs --json
node --experimental-strip-types --test tests/desktop/distribution.test.ts
```

脚本只读取源码清单、文件名和运行资源元信息，不启动 Electron/DSH，不联网，不安装依赖，不读取 `%APPDATA%/neko-fish`，不解析或输出密钥。当前默认开发路径结果为 **7 项明确缺项、5 项人工验收**；其中外部运行路径及 stub 是开发环境检查结果，不代表成品仍使用 stub。依赖路径或源码改变后应重新执行。

- `present`：指定文件或静态条件存在，不能证明其功能、版本、架构或许可已验收。
- `blocked`：本次检查发现明确缺项，退出码为 `1`。
- `manual`：静态检查无法证明的要求；没有明确缺项时仍以 `2` 退出。
- `releaseReady` 始终为 `false`。本脚本是源码与本地运行资源预检，不是安装包发布批准器。

路径与开发入口一致，可使用 `NEKO_FISH_ELECTRON`、`NEKO_FISH_ASSETS_DIR`、`NEKO_FISH_DSH_RUNTIME`、`NEKO_FISH_DSH_PRIMARY_RUNTIME` 指向已有本地资源。脚本检查真实路径，指向源码目录外的软链接/目录联接不会被当成独立交付。成品独立使用 `build-portable.mjs --verify` 和 `portable-smoke.mjs` 验证真实包布局；源码检查不替代这两项验收。

## 配置、数据与包内容

聊天 API 是生成文字回复的接口，**不是 TTS**。API 密钥只通过桌宠设置页在本机填写；默认保存到 `%APPDATA%/neko-fish/secrets/chat-api-key.dpapi`，由 Windows DPAPI 保护。非秘密配置、角色用户副本、原始聊天、记忆与摘要、DSH profile 和产出也保存在独立用户数据目录，不能复制进发布包。

本次便携构建使用明确文件白名单；公开分发时也必须保持此边界：

- 包含实际使用的桌面入口、renderer、业务模块、初始人设、锁定后的运行资源和许可说明。
- 排除真实 `app-config.json`、`secrets/`、`.env*`、DPAPI 文件、SQLite 数据库及旁路文件、DSH 登录/cookie/profile、个人 workspaces、日志、测试截图和调试产物。
- 旧 `services/neko-*` 和其 vendor 属于后续适配范围，当前 v1 不应因为位于同一源码树就自动整包携带。
- 自定义人设和用户记忆在升级时保留；初始人设只用于首次初始化。DPAPI 密文不能当作可在另一 Windows 用户/机器直接使用的通用配置。

预检对敏感文件只扫描源码根目录与 `config/` 的名称，不检查完整最终包、文件内容或所有嵌套目录，因此不能把该项通过描述为“完整凭据扫描通过”。
