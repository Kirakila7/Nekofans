# 任务与子代理的喷泉出场、邻近聚集

N.E.K.O. 工作台的真实 DSH 任务角色与 native subagent 共用一套桌面窗口运动。主角色保持原来的大号形象，中号任务和小号子代理继续使用各自的会话、外观与缩放设置。运动不创建新任务，也不把普通任务伪装成子代理。

主角色右键 → **设置** 中提供两个默认开启、保存到当前存档的选项：

- **任务与子代理喷泉出场**：同一会话身份在本次应用运行中第一次以活动角色显示时，从主角色身后沿抛物线喷出。不同角色略微错开，约 0.9～1.18 秒落下；刷新、切换皮肤、数量轮换或任务晋升为子代理不会重复播放。先显示为静止常驻角色的身份也不会在恢复活动时重新出生。
- **DBSCAN 邻近聚类与避让**：以角色可见身体中心做 DBSCAN，`minPoints=2`（包含自身），邻域半径为身体宽度中位数的 2.4 倍、至少 64 个屏幕逻辑像素。密度相连的邻居优先安排在一起；孤立角色也会在主角色周围找到落点。位置分配按身体尺寸避开主角色和已放置角色，运动途中用有速度上限的局部分离力避让。DBSCAN 负责识别邻居，落点分配和避让分别执行。

落点会在同伴加入或退场时保留，避免整群突然换位。主角色移动、显示工作区或角色尺寸改变后会重新计算；每个原生窗口都限制在所选屏幕工作区内。所有窗口共用一个 40ms 时钟，邻近分组每 240ms 更新，支持现有 1～32 个显示名额。

大肥鱼、跑动小猫、Claude 娘、Gemini 小猫、像素 Q 版及自定义动画共用运动行为。原有“小猫自由探索”开启时，活动小猫落地后继续探索；关闭它即可让小猫也留在群落中。形象内部的 GIF/WebP 或视频动画继续按真实任务状态播放。

鼠标悬停、窗口聚焦、输入和拖拽会暂停运动；拖拽结束后保留 3 秒操作时间。任务完成时角色归队、短暂停留后退场；常驻角色保留在落点。系统“减少动态效果”会取消喷泉和自由运动，完成归队使用静止定位。关闭两个新选项可恢复原有排列与显示方式，小猫探索选项独立控制。

## 验证

```sh
npm test
npm run check:neko

# 可选：macOS 原生窗口验证，填写本机 Electron 路径及证据目录。
NEKO_MOTION_EVIDENCE=/absolute/path/to/evidence \
  /absolute/path/to/Electron tests/neko-workbench/subagent-motion-native-qa.cjs
```

离线测试覆盖 DBSCAN、不同尺寸与负坐标屏幕、喷泉、首次可见时钟、身份晋升去重、暂停、归队、常驻保留和邻居退场后的落点稳定性。可选原生验证加载生产 main/preload/renderer，在临时隔离存档中打开 7 个真实 Electron 窗口，检查位置、前后顺序、出场画面居中、交互暂停、完成归队和减少动态效果，输出原生窗口 PNG 与 JSON 记录。

原生验证使用 DSH 协议事件夹具，密钥可用性在测试进程内设为不可用，不读取用户钥匙串、不调用模型供应商。截图来自真实窗口，不能替代真实 DSH 模型任务或 Windows 原生运行验收。临时存档在正常退出时清理，证据目录保留供复核。
