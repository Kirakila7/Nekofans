# 本地 N.E.K.O. 聊天工具

在源码目录里用 Node.js 24 运行。先启动本机 N.E.K.O.，再执行

```sh
node tools/local-neko-chat/index.cjs http://127.0.0.1:48911 大肥鱼
```

地址和角色可省略，默认使用示例里的值。如果服务器没有「大肥鱼」，保留的旧连接实现会用原角色模板创建它。指定其他角色时，请使用已存在的名字。输入 `/exit` 可退出。

这是单独运行的文字聊天工具，只接受本机 HTTP 服务地址。它使用 N.E.K.O. 的原有角色和服务端记录，不读取 Nekofans 的聊天资料、API 密钥或工作台账号。升级 Nekofans 时，旧本地连接设置和历史仍留在原资料中。
